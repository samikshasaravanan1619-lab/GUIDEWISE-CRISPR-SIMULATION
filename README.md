# GUIDEWISE-CRISPR-SIMULATION
GUIDEWISE is an interactive CRISPR educational simulation platform developed using Python and Streamlit. It provides a collection of learning and analysis modules for exploring synthetic DNA sequences, guide RNA matching, PAM recognition, mismatch detection, hypothetical editing visualization, mutation analysis, DNA alignment,,etc
🧬 GUIDEWISE – CRISPR Educational Simulation Platform

An Interactive Python-Based Platform for CRISPR Learning, DNA Sequence Analysis and Bioinformatics Education.

GUIDEWISE is a single-file Streamlit educational simulation platform designed to explore CRISPR-Cas concepts and DNA sequence analysis using artificial and synthetic sequences.

The platform combines guide RNA matching, PAM recognition, mismatch detection, mutation comparison, DNA analysis tools, genetics learning modules, sequence storage, interactive games, and downloadable reports in one application.

 Key Features

1. CRISPR Simulation Lab

- Guide RNA and synthetic DNA sequence comparison.
- Forward and reverse strand scanning.
- Mismatch count and mismatch position identification.
- PAM pattern recognition (NGG, NAG and NGA).
- Candidate target region identification.
- Educational off-target sequence similarity comparison.
- Hypothetical editing visualization.

2. DNA Analysis Lab

- Nucleotide Composition Analyzer.
- GC Content Analyzer.
- Sequence Statistics.
- DNA Alignment.
- Mutation Checker.
- Complementary Strand Generator.
- Codon Translation.
- Repeated Sequence Finder.
- GC Distribution Analyzer.
- DNA Palindrome Finder.

3. Mutation Checking Module

- Before-and-after DNA sequence comparison.
- Substitution identification.
- Insertion identification.
- Deletion identification.
- Total difference event calculation.
- Difference position reporting.
- Visual sequence comparison.
- Downloadable mutation comparison report.

4. Genetics & Inheritance Lab

- DNA Relationship Learning.
- Paternity & Kinship Education.
- Fictional genetic marker demonstrations.
- Educational explanations of inheritance concepts.

5. DNA Storage Repository

- Store synthetic DNA and RNA sequences during the application session.
- Assign records to Person 1 or Person 2.
- Add sequence names, categories, tags and notes.
- Search and filter stored sequences.
- View sequence length and GC content.
- Generate reverse complements for DNA records.
- Delete stored records.
- Export repository data in CSV and FASTA formats.

6. DNA Game Zone

Includes five interactive learning games:

- DNA Base Pairing Challenge.
- Find the Mutation.
- DNA Sequence Puzzle.
- Codon Matching Game.
- DNA Structure Identification.

7. Learning & Reports

- Interactive CRISPR and DNA quiz.
- Results and Reports module.
- Biology Learning Hub.
- Guide RNA characteristics.
- Cas protein educational information.
- Chromatin accessibility concepts.
- Downloadable sequence analysis reports.
- About & Limitations section.

⚙️ Installation and Setup

Prerequisites

- Python 3.9 or above.
- pip package manager.

Step 1: Clone the Repository

git clone https://github.com/samikshasaravanan1619-lab/GUIDEWISE-CRISPR-Simulator.git

Step 2: Open the Project Folder

cd GUIDEWISE-CRISPR-Simulator

Step 3: Install Dependencies

pip install -r requirements.txt

Step 4: Run the Application

streamlit run appmain.py

The application will open in your default web browser.

⚠️ Disclaimer and Limitations

GUIDEWISE is strictly an educational computational simulation.

- Use only artificial and synthetic example sequences.
- It is not a laboratory tool or genome editor.
- It does not perform actual genetic editing.
- Sequence similarity does not establish biological activity.
- PAM recognition is a separate computational observation.
- Mismatch counts do not establish actual off-target activity.
- Chromatin accessibility is explained conceptually and is not measured.
- The mutation checker identifies computational string differences, not clinically validated mutations.
- Genetics and relationship modules use fictional educational examples and cannot establish biological relationships.
